# Social Media Influence on Teen Lifestyle & Well-Being

This project analyzes social media usage patterns and their relationship with wellness, lifestyle behaviors, and academic outcomes among adolescents.

## Objectives

- Understand how much time teens spend on social media and on which platforms
- Explore the link between social media usage and mental health and well-being
- Examine the effect of usage on lifestyle habits such as sleep and physical activity
- Study the relationship between social media usage and academic performance
- Present the findings through an interactive Power BI dashboard and a written report
